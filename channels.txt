# ================== 频道表（直接在 GitHub/Gitee 网页上编辑这个文件即可）==================
# 规则：
#   1. 一行一个频道，【上下顺序 = 电视上的顺序】。想调顺序就剪切粘贴整行。
#   2. 方括号行（例如 [陕西]）开始一个分组，分组名就是电视上看到的分组；分组的上下顺序 = 电视上分组的顺序。
#   3. 第一个分组的第一个频道 = 打开 App 默认播放的频道（目前是陕西卫视）。
#   4. 行首加 # 表示暂时不要这个频道（不用删）。
#   5. 写法：显示名 = 别名1, 别名2
#      显示名的第一个词用来匹配直播源里的频道名；= 后面写源里可能出现的其他叫法（可省略）。
#   6. 以 * 开头的行 = 自动收录：名字以这些词开头、上面没写到的频道都按字母顺序放在这里。
#      例如 [陕西] 分组里的  * 陕西 西安
#   7. 改完点“提交/保存”，几分钟后自动重新生成；电视每天自动刷新（也可在 App 里手动刷新）。
#   8. 换省份：把 [陕西] 分组整段换成你的省份频道，并改 * 那一行的关键词。
# ==========================================================================================
